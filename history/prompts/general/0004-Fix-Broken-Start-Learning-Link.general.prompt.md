# Fix Broken Start Learning Link

## Context
The "Start Learning" link on the homepage was broken, causing a "page not found" error. The sidebar was autogenerated and working correctly, and the navbar "Start Learning" link was also working.

## Investigation
- Examined the index.tsx file and found the incorrect path `/docs/introduction-physical-ai/01`
- Checked the actual documentation structure and found the correct path should be `/docs/textbook/modules/01-introduction-physical-ai/theory`
- Verified the file existed at the correct location

## Solution
- Updated the link in `/mnt/d/Code/hackathon/book_project/my-book/src/pages/index.tsx` from `/docs/introduction-physical-ai/01` to `/docs/textbook/modules/01-introduction-physical-ai/theory`
- Also updated the corresponding navbar link in docusaurus.config.ts for consistency

## Files Changed
- `/mnt/d/Code/hackathon/book_project/my-book/src/pages/index.tsx`
- `/mnt/d/Code/hackathon/book_project/my-book/docusaurus.config.ts`
