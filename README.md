\# 📘 Physical AI \& Humanoid Robotics Textbook



This project was developed as part of my \*\*Agentic AI \& Cloud Computing coursework (GIAIC)\*\* using a spec-driven development approach.



It is a structured digital textbook designed to teach \*\*Physical AI \& Humanoid Robotics\*\* concepts in an organized, chapter-based format.



\---



\## 🚀 Live Project

🔗 https://bismahashmi2.github.io/Hackathon-3



\---



\## 🎯 Project Goal



The goal of this project was to explore how \*\*AI-assisted and spec-driven development workflows\*\* can be used to generate structured educational content.



Instead of manually building every section, I focused on defining structured requirements and using AI tools to generate and organize the textbook content.



\---



\## 🧠 What I Did



\- Defined structured course requirements using \*\*Spec-Kit Plus\*\*

\- Used \*\*Claude Code\*\* to generate textbook content from specifications

\- Organized the output into a \*\*Docusaurus-based documentation site\*\*

\- Deployed the final project using \*\*GitHub Pages\*\*



\---



\## ⚙️ Tech Stack



\- Docusaurus

\- Markdown

\- Spec-Kit Plus

\- Claude Code

\- GitHub Pages
